2. Greedy is not guaranteed to return the optimal solution because it checks for any possible combination of valid(considering the weight limit) trips that can transport all of the cows.

3. Brute force returns the optimal solution because it searches for every possible combination of valid trips that can transport all of the cows and chooses the combination with least trips.
